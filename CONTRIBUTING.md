# Contributing to Anki Interactive Manual

Thank you for helping improve this project!

## Ways to Contribute
- **Report an issue or suggest an edit:** Use the **Suggest an edit ↗** link on any manual page or open a [Manual Feedback Issue](https://github.com/saadrehman-med/Anki-Interactive-Manual/issues/new?template=manual-feedback.yml).
- **Request an interactive walkthrough:** Open a [Tutorial Request](https://github.com/saadrehman-med/Anki-Interactive-Manual/issues/new?template=tutorial-request.yml).
- **Ask questions or share thoughts:** Join [GitHub Discussions](https://github.com/saadrehman-med/Anki-Interactive-Manual/discussions) or comment directly on any page via Giscus.
- **Submit a Pull Request:** Fork the repo, update relevant files in `docs/manual/`, `recipes/`, or `quartz/`, and open a Pull Request.

## Guidelines
- Keep `docs/manual/` prose faithful to the [Official Anki Manual](https://docs.ankiweb.net/) (`ankitects/anki`).
- Use only the isolated `sandbox-anki/` profile (`DemoUser` and `Demo deck`) when capturing screenshots.
- Do not include personal information, local OS file paths, personal Anki profile data, or API keys.

Thank you!
